# Archive

The design and build spec of v1, written before this repo adopted its current
workflow ([`AGENTS.md`](../../AGENTS.md)). Kept for reference: what v1 was
meant to be, and the decisions (S1–S20) it was built on.

**Not contract.** [`SPEC.md`](../../SPEC.md) is the source of truth for what
to build. Where these documents and the spec disagree, the spec wins; where
the spec is silent, these are background, not requirements.

| Document | Holds |
|---|---|
| [`v1-conceptual-design.md`](v1-conceptual-design.md) | What the studio is for: the workspace, instruments of play, the board, the log, batches. |
| [`v1-spec.md`](v1-spec.md) | The v1 build spec: stack, architecture, the project folder, the engine, milestones M0–M3, decisions S1–S20. |
